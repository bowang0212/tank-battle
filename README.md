# Tank Battle

一个无需安装依赖、可直接在浏览器运行的简易坦克大战小游戏。

## 目录结构

```text
.
├── index.html
├── README.md
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       ├── config.js
│       ├── collision.js
│       ├── game.js
│       ├── input.js
│       ├── main.js
│       ├── ui.js
│       └── utils.js
└──
```

## 运行

直接用浏览器打开仓库根目录中的 `index.html` 即可。

## 操作

- `W` / `A` / `S` / `D` 或方向键：移动
- `空格`：发射炮弹
- `P`：暂停或继续
- 点击“重新开始”：重开一局

击败所有敌方坦克即可获胜；玩家被击中三次则游戏结束。游戏使用原生 HTML、CSS 和 JavaScript，无需第三方依赖或构建步骤。
