# Tank Battle Pro

使用原生 HTML、CSS、JavaScript 和 Canvas 实现的坦克大战小游戏。

## 运行

用浏览器直接打开仓库根目录中的 `index.html`。游戏无需安装依赖或构建。

## 操作

- 用 `W` / `A` / `S` / `D` 或方向键移动，按住空格连续射击。
- 按 `P` 或点击工具栏的“暂停”按钮暂停。点击“继续战斗”可以从原处恢复，点击“重新开始”会重回第 1 关。
- 在窄屏或触屏设备上，按住屏幕上的方向键和 FIRE，可以同时移动和射击。
- 切到其他标签页时，游戏会暂停。返回后可手动继续。
- 工具栏可开关音效。浏览器允许本地存储时，游戏会保存最高分。

## 战役规则

战役共 9 关，第 3、6、9 关有 Boss。每关消灭全部敌军后获得 250 分并进入下一关，清完第 9 关即获胜。初始有 3 条命，生命降为 0 时战役结束。

击毁敌军有机会掉落补给。蓝色护盾可在 8 秒内挡一次攻击，绿色维修补给恢复 1 条命（最多 5 条），黄色加速补给持续 5 秒。暂停期间补给效果计时冻结，重复拾取加速补给会刷新时长。

## 回归测试

在仓库根目录使用 Node.js 18 或更高版本运行：

```sh
node --test tests/game.test.cjs
```

测试运行页面的内嵌脚本，并使用模拟的 DOM、输入和帧时钟覆盖开局、暂停、恢复、重开、补给、碰撞、Boss 和终局。Canvas 显示、音频和设备触控需要在浏览器中检查。
